# 03-指令語法全介紹

## 總覽：指令分類

| 分類           | 指令                 | 資料流向              | 一句話說明                                   |
| -------------- | -------------------- | --------------------- | -------------------------------------------- |
| 雙向綁定       | `v-model`            | data ⇄ View           | 表單輸入與資料同步                           |
| 渲染（文字）   | `v-text`、`{{...}}`  | data → View           | 把資料顯示成文字                             |
| 渲染（HTML）   | `v-html`             | data → View           | 把資料當成 HTML 解析後顯示                   |
| 渲染（一次性） | `v-once`             | data → View（僅一次） | 只渲染一次，之後資料變動也不再更新           |
| 渲染（列表）   | `v-for`              | data → View           | 依陣列／物件重複產生元素                     |
| 渲染（條件）   | `v-if`、`v-show`     | data → View           | 依條件決定元素是否顯示                       |
| 屬性綁定       | `v-bind`、`:...`     | data → View           | 把資料綁定到 HTML 屬性（src、class、style…） |
| 事件綁定       | `v-on:click`、`@...` | View → data           | 使用者操作後觸發方法，改變資料               |

> 口訣：**v-model 雙向、渲染單向（資料 → 畫面）、事件反向（畫面 → 資料）**。

---

## View

### 一、雙向綁定

#### `v-model`

- **意義**：在表單元素（`input`、`textarea`、`select`、checkbox、radio）上建立「資料 ⇄ 畫面」雙向綁定。使用者輸入會更新 data，data 改變也會更新畫面。
- **範例**：

```html
<div id="app">
  <input type="text" v-model="text" />
  <p>你輸入的是：{{ text }}</p>
</div>

<script>
  Vue.createApp({
    data() {
      return { text: "" };
    },
  }).mount("#app");
</script>
```

- **補充**：
  - 修飾符：`v-model.trim`（去頭尾空白）、`.number`（轉數字）、`.lazy`（change 後才同步）。
  - 本質是語法糖：`:value="text"` + `@input="text = $event.target.value"`。

---

### 二、渲染方法

#### `{{...}}`（Mustache 插值）

- **意義**：在模板中插入 data 的值，支援單一 JavaScript 表達式（運算、三元、呼叫方法）。
- **範例**：

```html
<p>{{ message }}</p>
<p>{{ price * 2 }}</p>
<p>{{ isLogin ? '歡迎回來' : '請登入' }}</p>
```

- **注意**：載入慢時可能閃現 `{{ }}` 原始字樣（可用 `v-cloak` 處理）。
- **補充：如何在畫面上顯示 `{{ message }}` 原始字樣（含兩個大括號）**
  Vue 會把 `{{ }}` 當成插值編譯，若想原樣輸出，有以下做法：

```html
<!-- 方法一：v-pre（推薦）跳過該元素及子節點的編譯，內容原樣輸出 -->
<p v-pre>{{ message }}</p>

<!-- 方法二：用插值輸出字串，再包大括號 -->
<p>{{ '{{ message }}' }}</p>

<!-- 方法三：HTML 實體（&#123; = {、&#125; = }） -->
<p>&#123;&#123; message &#125;&#125;</p>

<!-- 方法四：data 中存字串，再用插值顯示 -->
<p>{{ raw }}</p>
<!-- data() { return { raw: '{{ message }}' } } -->
```

- 畫面皆顯示：`{{ message }}`
- `v-pre` 最直覺，適合整段含有大量 `{{ }}` 的內容（如教學文件、程式碼範例）。
- 注意：`v-pre` 會讓該元素內**所有** Vue 語法失效，若同一元素內還需要其他插值就不能用，請改用方法二或三。

#### `v-text`

- **意義**：把元素的 `textContent` 設為資料值，效果等同 `{{...}}`，但會**整個取代**元素內原有內容，且不會有閃現問題。
- **範例**：

```html
<p v-text="message"></p>
<!-- 等同 <p>{{ message }}</p> -->
```

- **`{{...}}` vs `v-text`**：

|        | `{{...}}`        | `v-text`           |
| ------ | ---------------- | ------------------ |
| 寫法   | 可混在文字中間   | 寫在標籤屬性上     |
| 內容   | 可與其他文字並存 | 覆蓋元素內所有內容 |
| 常用度 | 高               | 低                 |

#### `v-html`

- **意義**：把資料值當成 **HTML** 解析並設為元素的 `innerHTML`。`{{...}}` 與 `v-text` 都會把內容當純文字（HTML 標籤會被跳脫），需要顯示帶標籤的內容時才用 `v-html`。
- **範例**：

```html
<div id="app">
  <p>{{ rawHtml }}</p>
  <p v-html="rawHtml"></p>
</div>

<script>
  Vue.createApp({
    data() {
      return { rawHtml: '<span style="color: red">紅色文字</span>' };
    },
  }).mount("#app");
</script>
```

- **結果**：第一行會原樣顯示 `<span ...>` 字串；第二行則顯示紅色的「紅色文字」。
- **注意**：
  - **有 XSS 風險**：絕對不要對使用者輸入或不可信的內容使用 `v-html`。
  - 會覆蓋元素內原有內容，且內容裡不能再使用 Vue 模板語法（不會被編譯）。

#### `v-once`

- **意義**：元素與其子節點只渲染**一次**，之後即使資料改變也不再更新，視為靜態內容。可用來優化效能，或顯示「初始值快照」。
- **範例**：

```html
<div id="app">
  <input v-model="msg" />
  <p>會更新：{{ msg }}</p>
  <p v-once>不會更新：{{ msg }}</p>
</div>

<script>
  Vue.createApp({
    data() {
      return { msg: "Hello" };
    },
  }).mount("#app");
</script>
```

- **結果**：修改輸入框時，第二行跟著變，第三行永遠停在初始的 `Hello`。
- **補充**：`v-once` 可寫在任何元素上，包含其所有子節點；適合不會變動的大段內容。

#### `v-for`

- **意義**：依陣列（或物件、數字）重複渲染元素，語法 `item in list` 或 `(item, index) in list`。建議搭配唯一的 `:key`。
- **範例**：

```html
<ul>
  <li v-for="(item, index) in list" :key="item.id">
    {{ index + 1 }}. {{ item.name }}
  </li>
</ul>

<script>
  Vue.createApp({
    data() {
      return {
        list: [
          { id: 1, name: "蘋果" },
          { id: 2, name: "香蕉" },
        ],
      };
    },
  }).mount("#app");
</script>
```

- **補充：渲染物件的所有 key、value**
  - `v-for` 遍歷物件時，參數順序為 `(value, key, index)`：第一個是**值**、第二個是**鍵**、第三個是**索引**（皆可省略後面的參數）。
  - 注意順序是「value 在前、key 在後」，與 `Object.entries()` 的 `[key, value]` 相反。

```html
<ul>
  <li v-for="(value, key, index) in user" :key="key">
    {{ index }}. {{ key }}：{{ value }}
  </li>
</ul>

<script>
  Vue.createApp({
    data() {
      return {
        user: {
          name: "Kent",
          age: 30,
          city: "Taipei",
        },
      };
    },
  }).mount("#app");
</script>
```

- **結果**：
  ```
  0. name：Kent
  1. age：30
  2. city：Taipei
  ```
- 只要值：`v-for="value in user"`；要值與鍵：`v-for="(value, key) in user"`。
- 順序依 `Object.keys()` 的結果；`:key` 可直接用物件的 `key`（物件內唯一）。

- **補充：使用 `<template>` 搭配 `v-for`**
  - `<template>` 是不會被渲染成真實 DOM 的「隱形容器」。當一次要為每筆資料渲染**多個同層元素**，又不想多包一層 `<div>` 時，可在 `<template>` 上使用 `v-for`。
  - `:key` 要寫在 `<template>` 上（Vue 3 的規則），不是寫在內部子元素上。
  - 內部的子元素不需要另外加 `key`。

```html
<dl>
  <template v-for="item in list" :key="item.id">
    <dt>{{ item.name }}</dt>
    <dd>{{ item.desc }}</dd>
  </template>
</dl>

<script>
  Vue.createApp({
    data() {
      return {
        list: [
          { id: 1, name: "蘋果", desc: "紅色的水果" },
          { id: 2, name: "香蕉", desc: "黃色的水果" },
        ],
      };
    },
  }).mount("#app");
</script>
```

- **結果（實際 DOM，沒有多餘的外層標籤）**：
  ```html
  <dl>
    <dt>蘋果</dt>
    <dd>紅色的水果</dd>
    <dt>香蕉</dt>
    <dd>黃色的水果</dd>
  </dl>
  ```
- **適用情境**：
  - `<dl>`／`<dt>`／`<dd>`、`<table>` 的 `<tr>` 等對結構有嚴格要求，不適合多包 `<div>` 的地方。
  - 搭配 `v-if`：在 `<template v-for>` 內層的元素上使用 `v-if` 做條件顯示（避免 `v-for` 與 `v-if` 寫在同一元素）。

#### `v-if`

- **意義**：條件為真才**建立** DOM 元素，為假則**移除**元素。可搭配 `v-else-if`、`v-else`（需緊鄰）。
- **範例**：

```html
<p v-if="score >= 90">優秀</p>
<p v-else-if="score >= 60">及格</p>
<p v-else>不及格</p>
```

#### `v-show`

- **意義**：元素一律存在於 DOM，只切換 CSS 的 `display: none`。不支援 `v-else`。
- **範例**：

```html
<p v-show="isOpen">我可以顯示或隱藏</p>
```

- **`v-if` vs `v-show`**：

|              | `v-if`                   | `v-show`                     |
| ------------ | ------------------------ | ---------------------------- |
| 作法         | 新增／移除 DOM           | 切換 `display`               |
| 初次渲染成本 | 條件為假時不渲染（較低） | 一律渲染（較高）             |
| 切換成本     | 高                       | 低                           |
| 適用情境     | 很少切換、條件複雜       | 頻繁切換（如分頁、下拉選單） |

### 三、屬性綁定

#### `v-bind` / `:`

- **意義**：把資料綁定到 HTML 屬性上（`{{...}}` 不能用在屬性內）。`:` 是 `v-bind:` 的縮寫，屬性值會被當成 JavaScript 表達式。
- **範例**：

```html
<img v-bind:src="imgUrl" :alt="imgAlt" />
<a :href="link">連結</a>
<button :disabled="isLoading">送出</button>
<div :id="`item-${id}`">動態 id</div>

<script>
  Vue.createApp({
    data() {
      return {
        imgUrl: "https://picsum.photos/100",
        imgAlt: "範例圖片",
        link: "https://vuejs.org",
        isLoading: true,
        id: 1,
      };
    },
  }).mount("#app");
</script>
```

- **布林屬性**：`disabled`、`checked`、`readonly` 等，值為 `true` 時加上屬性；`false`、`null`、`undefined` 時移除該屬性。
- **綁定 class**（物件／陣列語法）：

```html
<!-- 物件：key 為 class 名，value 為 true 時加上 -->
<p :class="{ active: isActive, 'text-danger': hasError }">物件語法</p>
<!-- 陣列：可混用字串與條件 -->
<p :class="['box', isActive ? 'active' : '']">陣列語法</p>
<!-- 可與一般 class 並存 -->
<p class="box" :class="{ active: isActive }">並存</p>
```

- **綁定 style**（物件語法，屬性用 camelCase 或加引號的 kebab-case）：

```html
<p :style="{ color: textColor, fontSize: size + 'px', 'background-color': bg }">
  行內樣式
</p>
```

- **補充：`:style` 的使用**（Vue 沒有 `v-style` 指令，樣式綁定是 `v-bind:style`，縮寫 `:style`）
  - **物件語法**：key 用 camelCase（`fontSize`）或加引號的 kebab-case（`'font-size'`），value 為資料或字串。
  - **綁定整個樣式物件**：資料多時可抽成 `data`，模板更乾淨。
  - **陣列語法**：可合併多個樣式物件，後面的會覆蓋前面同名屬性。
  - **與一般 `style` 並存**：靜態樣式寫 `style`，動態樣式寫 `:style`，Vue 會合併。
  - Vue 會自動為需要的屬性加上瀏覽器前綴（如 `-webkit-`）；數值屬性要自行加單位（`size + 'px'`）。

```html
<!-- 1. 物件語法 -->
<p :style="{ color: textColor, fontSize: size + 'px' }">物件語法</p>

<!-- 2. 綁定整個物件 -->
<p :style="boxStyle">綁定物件</p>

<!-- 3. 陣列語法：合併多個樣式物件 -->
<p :style="[baseStyle, overrideStyle]">陣列語法</p>

<!-- 4. 與靜態 style 並存 -->
<p style="margin: 8px" :style="{ color: textColor }">並存</p>

<!-- 5. 依條件切換 -->
<button :style="{ opacity: isLoading ? 0.5 : 1 }">送出</button>

<script>
  Vue.createApp({
    data() {
      return {
        textColor: "red",
        size: 20,
        isLoading: false,
        boxStyle: {
          color: "white",
          backgroundColor: "#42b883",
          padding: "8px",
        },
        baseStyle: { color: "blue", fontWeight: "bold" },
        overrideStyle: { color: "orange" }, // 最終 color 為 orange
      };
    },
  }).mount("#app");
</script>
```

- **何時用 `:style`、何時用 `:class`**：樣式值由資料動態決定（顏色、寬度、進度條百分比）用 `:style`；固定的一組樣式切換用 `:class`，較易維護。

- **動態屬性名稱**：`<a :[attr]="value">`，`attr` 為資料中的屬性名稱。
- **一次綁定多個屬性**：`<input v-bind="inputAttrs">`，`inputAttrs` 為物件（如 `{ type: 'text', placeholder: '請輸入' }`）。
- **同名簡寫（Vue 3.4+）**：屬性名與變數名相同時可省略值，`<img :src>` 等同於 `<img :src="src">`。
- **搭配 `v-for`**：常用來綁定 `:key`、`:src`、`:class` 等，如 `<li v-for="item in list" :key="item.id" :class="{ done: item.done }">`。

### 四、事件綁定

#### `v-on:click` / `@click`

- **意義**：監聽 DOM 事件，事件發生時執行指定方法或表達式。`@` 是 `v-on:` 的縮寫。
- **範例**：

```html
<button v-on:click="count++">+1（完整寫法）</button>
<button @click="add">+1（縮寫，呼叫方法）</button>
<button @click="say('Hi', $event)">傳參數</button>
<p>{{ count }}</p>

<script>
  Vue.createApp({
    data() {
      return { count: 0 };
    },
    methods: {
      add() {
        this.count++;
      },
      say(msg, e) {
        console.log(msg, e);
      },
    },
  }).mount("#app");
</script>
```

- **`@...` 泛指所有事件**：`@input`、`@change`、`@submit`、`@keyup.enter`、`@mouseover` …
- **修飾符**：`.prevent`（阻止預設行為）、`.stop`（停止冒泡）、`.once`（只觸發一次）。

## Vue元件

View 的指令負責「怎麼顯示、怎麼觸發」，而資料與邏輯放在 Vue 元件（Options API）內：

| 選項         | 說明                                  | 與指令的關係                                                                |
| ------------ | ------------------------------------- | --------------------------------------------------------------------------- |
| `data`       | 存放響應式資料                        | 被 `v-model`、`{{...}}`、`v-text`、`v-for`、`v-if`、`v-show`、`v-bind` 讀取 |
| `methods`    | 定義方法                              | 被 `@click` 等事件指令呼叫，並修改 `data`                                   |
| `life cycle` | 生命週期鉤子（`created`、`mounted`…） | 元件建立／掛載時自動執行，常用來初始化 `data`（如呼叫 API）                 |
| `watch`      | 監聽某個資料變化                      | `v-model` 等造成 data 改變時，觸發額外行為                                  |
| `computed`   | 計算屬性（有快取）                    | 可在 `{{...}}`、`v-for`、`v-if` 中使用，如過濾後的列表                      |

## 指令之間的關係

### 1. 資料流向圖

```
            ┌──────── v-model（雙向）────────┐
            ▼                                │
   ┌──────────────┐   {{...}} / v-text    ┌──┴───────┐
   │ data（資料） │ ───── v-for ────────▶ │  View    │
   │              │ ─ v-if/v-show/v-bind ▶ │ （畫面） │
   └──────────────┘                       └──┬───────┘
            ▲                                │
            └── methods ◀── @click ──────────┘
                 （事件觸發，修改資料）
```

### 2. 運作循環

1. **渲染**：`data` 透過 `{{...}}`／`v-text`／`v-for`／`v-if`／`v-show`／`v-bind` 呈現到畫面。
2. **互動**：使用者在畫面上輸入（`v-model`）或點擊（`@click`）。
3. **更新**：`v-model` 直接改寫 data；`@click` 呼叫 `methods` 再改寫 data。
4. **重新渲染**：data 改變 → Vue 自動更新畫面（響應式），回到步驟 1。

- 另請參閱[將todolist從JS轉到Vue](將todolist從JS轉到Vue.md)

## 重點整理

- **雙向綁定**：`v-model`（表單專用）。
- **渲染方法**：`{{...}}`、`v-text`（文字）、`v-html`（HTML，注意 XSS）、`v-once`（只渲染一次）、`v-for`（列表）、`v-if`／`v-show`（條件）。
- **屬性綁定**：`v-bind:src` ＝ `:src`，屬性值為 JS 表達式；`:class`、`:style` 支援物件／陣列語法；布林屬性為假值時會移除。
- **事件綁定**：`v-on:click` ＝ `@click`，`@...` 可用於任何事件。
- **三者分工**：渲染負責「資料 → 畫面」，事件負責「畫面 → 資料」，`v-model` 則兩者兼具。
- **資料與邏輯**：`data` 供指令讀取，`methods` 供事件呼叫，`computed`／`watch` 處理衍生與監聽，`life cycle` 處理初始化。
